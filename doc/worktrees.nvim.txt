1. Introduction                                      *worktrees.nvim-introduction*

worktrees.nvim is a Neovim plugin for seamless git worktree management with
buffer mirroring. It provides simple commands to add, switch, and remove git
worktrees while preserving your buffer layout across switches.

==============================================================================
2. Features                                              *worktrees.nvim-features*

- Easy Worktree Management: Add, switch, and remove git worktrees with simple
  commands
- Buffer Mirroring: Automatically mirrors your buffer layout when switching
  worktrees
- Event System: Emit autocmd events for custom workflows
- Fast: Built with `vim.system()` for optimal performance
- Type-Safe: Full LuaCATS annotations throughout

==============================================================================
3. Installation                                      *worktrees.nvim-installation*

Using lazy.nvim:
>lua
    {
      'ergotu/worktrees.nvim',
      config = function()
        require('worktrees').setup({
          level = vim.log.levels.INFO, -- Notification level
        })
      end,
    }
<

4. Usage                                                    *worktrees.nvim-usage*

Add a new worktree:
>
    :WorktreeAdd
<
- Enter a branch name
- If the branch exists, checkout to that branch
- If new, select a base reference (branch/tag/HEAD)

Switch worktrees:
>
    :WorktreeSwitch
<
- Select from available worktrees
- Your buffers will be mirrored to the new worktree

Remove a worktree:
>
    :WorktreeRemove
<
- Select the worktree to remove (current worktree excluded)
- Confirm the action

5. Commands                                              *worktrees.nvim-commands*

                                                                  *:WorktreeAdd*
:WorktreeAdd
    Create a new git worktree. Prompts for a branch name and base reference
    if creating a new branch. Automatically switches to the new worktree.

                                                               *:WorktreeSwitch*
:WorktreeSwitch
    Switch to an existing worktree. Presents a list of available worktrees
    for selection. Mirrors your buffer layout to the new worktree.

                                                               *:WorktreeRemove*
:WorktreeRemove
    Remove an existing worktree. Presents a list of worktrees (excluding the
    current one) and prompts for confirmation before removal.

6. Events                                                  *worktrees.nvim-events*

worktrees.nvim emits User autocmd events that you can hook into for custom
workflows:

                                                               *WorktreeCreated*
WorktreeCreated
    Triggered when a new worktree is created.
    Event data: { branch, path, previous_path, upstream? }

    Example:
>lua
    vim.api.nvim_create_autocmd('User', {
      pattern = 'WorktreeCreated',
      callback = function(event)
        print('Created worktree at: ' .. event.data.path)
      end
    })
<

                                                              *WorktreeSwitched*
WorktreeSwitched
    Triggered when switching to a different worktree.
    Event data: { path, previous_path }

    Example:
>lua
    vim.api.nvim_create_autocmd('User', {
      pattern = 'WorktreeSwitched',
      callback = function(event)
        print('Switched from: ' .. event.data.previous_path)
        print('Switched to: ' .. event.data.path)
      end
    })
<

                                                               *WorktreeRemoved*
WorktreeRemoved
    Triggered when a worktree is removed.
    Event data: { path }

    Example:
>lua
    vim.api.nvim_create_autocmd('User', {
      pattern = 'WorktreeRemoved',
      callback = function(event)
        print('Removed worktree at: ' .. event.data.path)
      end
    })
<

7. Configuration                                    *worktrees.nvim-configuration*

                                                              *worktrees.setup()*
worktrees.setup({opts})
    Setup function for worktrees.nvim. Call this in your config to initialize
    the plugin.

    Parameters:
      {opts}  (table|nil) Configuration options

    Fields:
      {level}  (integer|nil) Notification log level. Defaults to
               vim.log.levels.INFO. Can be set to vim.log.levels.DEBUG,
               vim.log.levels.WARN, or vim.log.levels.ERROR.

    Example:
>lua
    require('worktrees').setup({
      level = vim.log.levels.INFO,
    })
<
